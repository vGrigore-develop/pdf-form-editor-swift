# PDF Voucher Editor

A native macOS app for preparing fillable PDF voucher templates. It adds AcroForm text and image fields and cuts the page to a custom outline. The product and technical spec is in `SPEC.md`, implementation decisions are in `DECISIONS.md`, and the M0 spikes are in `spikes/`.

## Build and run

You need macOS 15 or later, Xcode 27 (command-line tools are enough) and network access for the first MuPDF download. MuPDF is not vendored in the repo: `scripts/build-mupdf.sh` downloads the pinned 1.28.2 source release from mupdf.com, verifies its SHA-256 and builds static libraries into `vendor/` (gitignored).

```
git clone https://github.com/vGrigore-develop/pdf-form-editor-swift.git
cd pdf-form-editor-swift
scripts/build-mupdf.sh          # once: downloads and builds MuPDF 1.28.2 into vendor/ (about 1 min)
scripts/build-app.sh            # builds "build/PDF Voucher Editor.app"
open "build/PDF Voucher Editor.app"
```

To open a PDF directly:

```
open -a "build/PDF Voucher Editor.app" Tests/Fixtures/synthetic_voucher.pdf
```

For a quick development loop without the app bundle:

```
swift run PDFVoucherEditor Tests/Fixtures/synthetic_voucher.pdf
```

The app icon is in `Resources/AppIcon/`; regenerate the `.icns` with `scripts/make-icon.sh`. The Liquid Glass version (`AppIcon.icon`, an Icon Composer document) is compiled by `build-app.sh` when Xcode 26+ is installed; see `Resources/AppIcon/README.md`.

The app saves into the file you opened, as an incremental update. Work on a copy when experimenting.

## Templates

No real templates are included. Everything under `Tests/Fixtures/` is synthetic and generated by the scripts in `spikes/` (`make_fixtures.py`, `make_svg_fixtures.py`, `make_example_template.py`, `s3_preservation.py`), apart from the Noto Sans font (SIL OFL, see `Tests/Fixtures/NotoSans-OFL.txt`).

`Tests/Fixtures/example_voucher_template.pdf` is a realistic example to try the app with: two landscape pages, an uncut template with a placed raster image, a 1 pt die line along a stepped left edge and a semicircular right end, and eight AcroForm fields (six text, two image slots, one of which crosses the stepped edge). Open it directly, or work on a copy:

```
open -a "build/PDF Voucher Editor.app" Tests/Fixtures/example_voucher_template.pdf
```

The smart-outline, field-crop and real-template tests (`RealTemplateTests`, `testExampleTemplateSnapshot`, `testExampleTemplateCrop`) and `spikes/s10_crop.py` run against it by default, so a plain `swift test` needs no setup.

To use your own template, open a copy of it in the app (`open -a "build/PDF Voucher Editor.app" /path/to/copy.pdf`). Keep real templates outside the repo, or in a `private/` folder, which is gitignored. The same tests and spike can run against your template instead of the example by setting an environment variable:

```
VE_TEMPLATE_PDF=/path/to/copy.pdf swift test      # RealTemplateTests, testExampleTemplateSnapshot, testExampleTemplateCrop
VE_TEMPLATE_IMAGE_FIELD=photo VE_TEMPLATE_PDF=/path/to/copy.pdf swift test   # which image field crosses the outline
cd spikes && ../.venv/bin/python s10_crop.py /path/to/copy.pdf
```

The shape and pixel assertions are written for the example template; with your own, the shape-specific ones are skipped or need adjusting.

## Tests

```
swift test
```

The Swift tests cover the model, geometry, the PDF syntax parser and content scanner, the MuPDF engine (round trips, the cut, JS and signature fixtures), and the canvas, driven by synthesized mouse and key events.

The Python spike checks run against the Swift engine's output. They need a local virtualenv (once, from the repo root: `python3 -m venv .venv && .venv/bin/pip install -r spikes/requirements.txt`), and S9/S10 also need `(cd spikes/node && npm ci)`:

```
cd spikes && S9_TEMPLATE=out/swift/swift_fields_and_cut.pdf ../.venv/bin/python s9_fill.py
```

`spikes/README.md` explains the spikes themselves.

## Using it

- **Tools:** V Select, T Text field, I Image field, O Outline (toolbar or keys).
- **Fields:** drag on the page to draw a field; a click makes a default-size field.
  - Select a field to move it or resize it with the 8 handles. Shift keeps the aspect ratio; Option resizes from the centre or, when dragging, duplicates.
  - Arrows nudge 1 pt, Shift-arrows 10 pt.
  - Moving and resizing snap (toolbar "Snap" toggle, grid 1/2/5/10 pt, optional grid overlay; both also in the View menu) to other fields' edges and centres, the page edges and centre, the outline's bounding edges, then the grid, within 6 screen pixels. Orange guide lines show the alignment; hold Cmd to disable. Arrow nudges never snap.
  - Delete removes the field and Cmd-D duplicates it.
- **Inspector:** name, tooltip, flags, rect, font size and colour, alignment, multiline, max length, comb, default value, colours, and for images the `/IF` fit and the click-to-insert action. Fields exported as a field plus one separate widget (Illustrator/InDesign) are read-only until "Merge field and widget" (inspector or the field list's context menu) combines them; names, rects and looks do not change.
- **Outline (O):** "New from Rectangle" or "New Voucher Shape" in the inspector, or click points and click the first point to close.
  - Drag points to edit (they snap to the grid and to other points).
  - Option-click a segment to insert a point; Delete removes the selected point.
  - Each segment can be switched between line and arc.
  - "Crop fields to outline" (on by default) clips fields that cross the outline and adds a white cover annotation over the outside, so filled images and flattened fields do not show outside the shape. "Fit to Outline" in the field inspector shrinks a crossing field to fit inside.
  - "Remove Cut" restores the page exactly, field appearances included.
- **Edit / Preview (Cmd-P):** Preview shows the page with stored appearances, sample text and the cut, built in memory.
- **Save (Cmd-S):** runs the programmatic-fill checks (SPEC 6.2) and appends an incremental update.

## Layout

```
Sources/VoucherModel      pure Swift model: Template, FieldDef, Outline, naming, save checks, undoable editor
Sources/VoucherGeometry   arc -> Bézier, outline validation, containment, point insert/remove
Sources/PDFEngine         PDFEngine protocol, PDF object syntax parser, q/Q scanner, cut encodings
Sources/Appearance        /AP /N streams for text fields and image placeholders
Sources/CMuPDFShim        the C shim over MuPDF (fz_try everywhere; strings in, strings out)
Sources/MuPDFEngine       reader, key-level writer, cut writer, incremental save
Sources/VoucherEditorApp  AppKit/SwiftUI app: NSDocument, canvas overlay on PDFView, inspector, sidebar
Tests/                    XCTest targets + Fixtures/
scripts/                  build-mupdf.sh, build-app.sh, make-icon.sh, make-liquid-icon.sh
Resources/AppIcon/        app icon sources (SVG), the committed AppIcon.icns and the AppIcon.icon document
spikes/                   M0 Python spikes (S1, S3, S5, S7, S9) and results
```

Debug aid: `VE_SNAPSHOT_DIR=/tmp/snaps .build/debug/PDFVoucherEditor file.pdf` writes PNGs of the window in Edit, Selected, Outline and Preview states, then quits.
